THE STATIC COLLECTIVE / MAIL-004

Your phone. Your door.

This page invokes your browser's real WebAuthn passkey prompt. It does not send any data to a network service. Paste a locally issued challenge, approve on your device, then carry the JSON response back to your trusted local verifier.

Prototype, not a hosted mail service. Works only at its configured secure WebAuthn origin. For the first local experiment, serve this repository at http://localhost:8000 with RP ID localhost. On a separate phone, localhost means the phone itself: using a real phone requires hosting this page on a controlled HTTPS domain and issuing challenges bound to that exact domain.

01 / Register a passkey

Paste a PostEmahh'n registration ticket issued for your address. Registration additionally needs a separately verified signature from the mail-owner key; browser registration by itself does not add a trusted identity.

02 / Authorize a print request

First inspect the independently signed print request: station, document hash, address, and expiration. This browser does not validate the station key. The recipient must verify that identity using the trusted PostEmahh'n verifier before approving.

03 / Verification packet

Copy this response to the station-side verifier; it cannot print anything simply because this JSON exists.
